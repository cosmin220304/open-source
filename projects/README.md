# Projects

Each subdirectory here is an independent project with its own README, dependencies,
tests, and license.

Browse the [project catalog](../README.md#projects) or follow the
[guide to adding a project](../CONTRIBUTING.md#add-a-project).

Use `projects/<project-name>/` for all files belonging to a project. This directory
is not a shared package or application workspace. The root README is the catalog;
do not maintain a second project list here.
